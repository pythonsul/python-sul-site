Hey there! Another big name confirmed as a keynote at Python Sul 2025.  
We’re thrilled to announce that Hisham H. Muhammad will be the **second keynote** of the event! Grab your mate and get ready to learn more about this legend.  

If you’ve ever used Linux, you’ve probably run into **htop**, the interactive process viewer that makes the command line feel almost poetic. It was created by **Hisham H. Muhammad**, who, in addition to contributing to htop, is the main author of **LuaRocks**, the package manager for Lua, and one of the founders of **GoboLinux**, a distribution that redefines the operating system directory structure.  


{{< image src="images/posts/hishamhm/porquechorasfirefox.png" alt="htop running (almost a FirefoxOS)" >}}

## Who is Hisham H. Muhammad?

Currently living in Porto Alegre, Brazil, Hisham is a free software and functional programming enthusiast. He shares his journey and projects on his personal website, where he also maintains a blog with reflections on technology, culture, and society.  

{{< iframe src="https://www.youtube.com/embed/L25waVhy78o?si=Z91le2p516nTOgpl" title="Adding performance counters to htop" >}}

## Notable Projects

- **[htop](https://htop.dev/)**: An interactive process viewer for Unix systems, replacing the traditional `top` with a friendlier interface and extra features.  
- **[LuaRocks](https://luarocks.org/)**: The package manager for Lua, making it easy to install and manage libraries.  
- **[GoboLinux](https://www.gobolinux.org/)**: A Linux distribution that proposes a new directory structure, simplifying the system and easing administration.  
- **[Teal](https://teal-language.org/)**: A programming language that adds static typing to Lua while keeping its simplicity and flexibility.


## Contributions and Recognition

Hisham has been a regular presence at free software conferences, such as **FOSDEM**, sharing his experiences and learnings with the community. His work has impacted the Lua ecosystem and inspired developers worldwide to contribute to free software.
